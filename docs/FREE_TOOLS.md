# Бесплатные технологии и инструменты
Версия: 0.1

Документ фиксирует кандидатов для разработки. Наличие технологии в списке не означает, что она уже подключена к проекту.

## Основа первой версии

### Web Audio API
- Назначение: синтез звука, ритм, осцилляторы, фильтры, огибающие и эффекты прямо в браузере.
- Стоимость: встроен в современные браузеры, отдельная подписка не нужна.
- Интернет: для базовой работы после загрузки страницы не требуется.
- Ограничение: это не готовый оркестр и не реалистичный вокальный движок.

### HTML, CSS и JavaScript
- Назначение: интерфейс и логика приложения.
- Стоимость: бесплатные открытые веб-технологии.
- Плюс: не требуют обязательной установки тяжёлого программного пакета.

## Кандидаты для следующих этапов

### Tone.js
- Назначение: музыкальное планирование, синтез и работа с ритмическими событиями поверх Web Audio API.
- Лицензия: открытая MIT; перед включением фиксировать конкретную версию и лицензию.
- Ограничение: библиотека помогает строить музыкальный движок, но сама по себе не создаёт реалистичные голоса или готовые песни.

### FluidSynth и SoundFont
- Назначение: воспроизведение MIDI через наборы инструментальных тембров.
- Важно: проверять лицензию каждого SoundFont отдельно. Не все бесплатные для скачивания банки разрешают любое использование.
- Ограничение: качество зависит от набора звуков и размера файлов.

### Audacity
- Назначение: отдельная запись, редактирование и обработка аудио.
- Стоимость: бесплатная программа с открытым исходным кодом.
- Роль: вспомогательный инструмент, а не ядро браузерного приложения.

### OpenShot
- Назначение: монтаж музыкальных клипов из готовых видео, изображений и звуковых дорожек.
- Стоимость: бесплатный видеоредактор с открытым исходным кодом.
- Роль: создание видеоклипа после подготовки музыки и визуальных материалов. Не генерирует музыку и не создаёт исходные видеосцены.

## Правила выбора инструментов

1. Не подключать сервис, если для базовой работы обязательны платные токены или подписка.
2. Проверять лицензию кода, сэмплов, шрифтов и изображений отдельно.
3. Не считать «бесплатную пробную версию» постоянным бесплатным решением.
4. Не загружать крупные библиотеки на телефон без необходимости.
5. Не обещать экспорт, вокал или генерацию, пока функция не проверена в приложении.
6. По возможности сохранять список используемых библиотек и их лицензий в отдельном файле.

## Что пока не выбрано

- Бесплатный движок реалистичного синтеза вокала.
- Наборы волынки, скандинавских народных инструментов и хоровых сэмплов с подходящей лицензией.
- Способ экспорта готового аудио непосредственно из приложения.
- Механизм локального хранения больших библиотек звуков.

Эти решения будут приниматься после проверки реальных требований, лицензий, размера файлов и совместимости с Android.
