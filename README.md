# ORIGIN MUSIC ENGINE

**ORIGIN MUSIC ENGINE** — проект собственной музыкальной студии для создания оригинальных атмосферных композиций.

Цель — дать пользователю возможность управлять не только жанром или текстовым запросом, а самой музыкальной конструкцией: ритмом, темпом, голосами, инструментами, атмосферой, развитием и кульминацией.

## Принципы проекта

- Оригинальная музыка, без копирования конкретных произведений и узнаваемых партий существующих исполнителей.
- Управление композицией по отдельным параметрам, а не только одним текстовым запросом.
- Сочетание электронной основы, этнических тембров, голосов и атмосферных слоёв.
- Сначала бесплатная и локально запускаемая основа; платные сервисы не должны быть обязательными.
- Честное разделение реализованных функций и планов.

## С чего начать

1. Откройте файл `index.html` в современном браузере — когда появится первая рабочая версия.
2. Документы проекта находятся в папке `docs/`.
3. Текущая концепция эмоционального музыкального модуля: [EMOTIONAL_ENGINE.md](docs/EMOTIONAL_ENGINE.md).
4. Техническое устройство: [ARCHITECTURE.md](docs/ARCHITECTURE.md).
5. План разработки: [ROADMAP.md](docs/ROADMAP.md).
6. Бесплатные инструменты: [FREE_TOOLS.md](docs/FREE_TOOLS.md).

## Текущий статус

Сейчас в репозитории находится концептуальная спецификация эмоционального модуля и проектная документация. Полноценная генерация музыки, запись вокала и экспорт аудиофайлов пока не реализованы. Следующий этап — создать минимальный работающий аудиопрототип в браузере.

## Важное ограничение

Браузерный синтезатор сможет создавать оригинальные звуки и ритмические последовательности без внешнего сервиса. Реалистичные вокальные партии, сложные этнические инструменты и полноценное сведение потребуют отдельных бесплатных библиотек, записей или дополнительных модулей.
