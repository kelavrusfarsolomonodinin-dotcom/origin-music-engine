# ORIGIN MUSIC ENGINE

**ORIGIN MUSIC ENGINE** — проект собственной музыкальной студии для создания оригинальных атмосферных композиций.

Цель — дать пользователю возможность управлять музыкальной конструкцией: ритмом, темпом, тембрами, атмосферой, развитием и кульминацией.

## Принципы проекта

- Оригинальная музыка, без копирования конкретных произведений и узнаваемых партий существующих исполнителей.
- Управление композицией по отдельным параметрам.
- Сочетание электронной основы, этнических тембров, голосов и атмосферных слоёв.
- Бесплатная и локально запускаемая основа; платные сервисы не обязательны.
- Честное разделение реализованных функций и планов.

## Запуск

Публичная версия сайта будет доступна по адресу:

https://kelavrusfarsolomonodinin-dotcom.github.io/origin-music-engine/

Публикация выполняется автоматически через GitHub Actions при обновлении основной ветки. Если сайт ещё не открылся, проверьте выполнение публикации во вкладке Actions репозитория. Исходный файл приложения: `index.html`.

Для запуска звука нажмите «Создать и слушать». На телефоне браузер может потребовать нажатие на кнопку для разрешения воспроизведения.

## Что уже реализовано в прототипе 0.3

- Шесть эмоциональных профилей.
- Управление темпом и плотностью.
- Четыре части композиции: вступление, развитие, кульминация, завершение.
- Выбор ритмического рисунка.
- Настройка вариативности мелодической линии.
- Синтез звука через Web Audio API.
- Сохранение и загрузка настроек проекта в формате JSON.

## Что ещё не реализовано

- Реалистичные мужские и женские голоса, хор.
- Волынка и достоверные скандинавские инструменты.
- Полноценная гармоническая аранжировка и профессиональное сведение.
- Экспорт готовой композиции в WAV/MP3.
- Постоянная библиотека проектов внутри приложения.

## Важное ограничение

Текущий прототип — экспериментальный браузерный синтезатор, а не полноценная музыкальная студия. Он создаёт электронный эскиз. Реалистичные голоса и акустические инструменты потребуют отдельных лицензированных библиотек или собственных записей.
